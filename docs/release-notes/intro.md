# v1.0.0 Changelog

- Add [`onDataZoom`](../using-charts/supported-events.md#ondatazoom) eCharts event handling
- Add [`onDoubleClick`](../using-charts/supported-events.md#ondoubleclick) eCharts event handling
- Add [`onClick`](../using-charts/supported-events.md#onclick) eCharts event handling
- Add JS parser with new prop ([`enableJsFunctions`](../using-charts/common-options.md#enablejsfunctions))
- Add license check logic
- Add CSS variable support
- Remove old v0.1.0 props (`theme` and `clearOnReload` were removed)
